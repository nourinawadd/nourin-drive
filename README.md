# Welcome to my Portfolio's Code!
Here lies all of the code behind my personal website, as well as all the assets used :D

1. Learn Backend Basics (First 2-3 Weeks)
Since you already know Python and JavaScript, you can choose one of these:
Node.js (with Express.js) – If you want to stay in the JavaScript ecosystem.
FastAPI (Python) – Easier and faster for beginners.
Topics to cover:
Setting up a server
Creating API routes (handling requests/responses)
Connecting to a database (SQLite, PostgreSQL, or Firebase)
Deploying a backend server (e.g., on Render or Railway)
A great way to learn is by following a small "Build a REST API" tutorial.

2. Start Your Portfolio Website (Weeks 3-4)
Pick Next.js (easier for static + dynamic content).
Use GSAP and Framer Motion for animations.
Connect a simple backend (e.g., for contact form or project database).
Use Markdown files or a CMS like Contentful/Sanity to store project details.

3. Add Interactive Animations (Weeks 4-6)
GSAP for mouse interactions & motion paths
Locomotive Scroll for smooth scrolling
Framer Motion for UI transitions (if using React)

4. Deploy (Weeks 6-8)
Frontend: Deploy to Vercel or Netlify.
Backend: Use Railway.app or Render for hosting.
Domain: Get a free domain from Freenom or buy one from Namecheap
